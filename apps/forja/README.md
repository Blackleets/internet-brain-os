# Forja

Superficie TanStack de Efesto: yunque, tocho, contraste por capas (SHA-256 + Ed25519, sin eIDAS) y taller del dueño.

No sustituye `apps/dashboard`. Quien forja no necesita cuenta. Claves, agentes, actividad y conversación piden sesión (Google, X o correo). El Kernel sigue en el navegador.

Arranque: `npm install && npm run dev` (puerto 8080).
